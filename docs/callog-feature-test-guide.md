# 캘로그 기능 테스트 안내서

Callog를 처음 보는 사람도 사이트에 접속한 뒤 주요 기능을 순서대로 확인할 수 있도록 정리한 테스트 안내서입니다.

이 문서는 현재 프론트 화면 구조를 기준으로 작성했습니다.

## 1. 접속 및 로그인

### 1.1 로그인 화면 진입

실행 후 브라우저에서 프론트엔드 주소로 접속합니다.



### 1.2 로그인

1. 로컬 프론트엔드 주소에 접속합니다.
2. 안내받은 계정의 아이디와 비밀번호를 입력합니다.
3. 로그인 버튼을 클릭합니다.

기대 결과:

- 로그인 성공 시 대시보드 화면으로 이동합니다.
- 좌측 사이드바와 상단 헤더가 표시됩니다.
- 헤더에 프로필 또는 알림 영역이 표시됩니다.
- 새로고침 후에도 로그인 상태가 유지됩니다.

추가 확인:

- 로그아웃 상태에서 `/dashboard`에 직접 접근하면 로그인 화면으로 이동합니다.
- 로그인 후 원래 접근하려던 화면으로 이동하는지 확인합니다.
- 이미 로그인한 상태에서 `/user/login`에 접근하면 대시보드로 이동합니다.

### 1.3 계정 구조

회원가입은 외부 협력사를 위한 기능입니다.

본사 계정은 `admin`, `manager` 등 상위 권한 계정이 생성하여 전달하는 방식으로 설계되어 있습니다.

권한 테스트를 위해 다음 유형의 계정을 준비하는 것을 권장합니다.

- 본사 관리자
- PM 조직 매니저
- 계열사 매니저
- 외부 파트너
- 일반 사용자

## 2. 대시보드

### 2.1 화면 진입

로그인 후 기본 진입 화면은 대시보드입니다.

접속 경로:

```text
/dashboard
```

### 2.2 확인 항목

대시보드에서 다음 영역을 확인합니다.

- 전체 요약 카드
- 캠페인 현황
- KPI 관련 요약
- 검수 대기 또는 승인 대기 항목
- 캠페인 파이프라인
- 매출 추이
- 최근 활동

### 2.3 테스트 절차

1. 로그인 후 대시보드가 표시되는지 확인합니다.
2. 각 요약 카드의 숫자와 라벨이 정상 표시되는지 확인합니다.
3. 캠페인 현황 또는 검수 대기 항목을 클릭합니다.
4. 관련 캠페인 상세 화면으로 이동하는지 확인합니다.
5. 월간/분기 전환 버튼이 있는 경우 클릭해 데이터가 갱신되는지 확인합니다.

기대 결과:

- 대시보드 API 실패 시 전체 화면이 깨지지 않고 가능한 영역만 표시됩니다.
- 빈 데이터일 경우 빈 상태 안내가 표시됩니다.
- 상세보기 또는 카드 클릭 시 관련 화면으로 이동합니다.

## 3. 캠페인 생성 및 목록

### 3.1 캠페인 만들기

1. 좌측 사이드바 또는 캠페인 영역에서 캠페인 생성 버튼을 클릭합니다.
2. 다음 정보를 입력합니다.
   - 이름
   - 시작일
   - 종료일
   - 색상
   - 캠페인 설명
3. 생성합니다.

기대 결과:

- 사이드바 또는 캠페인 목록에 새 캠페인이 등장합니다.
- 선택한 색상이 카드 또는 상세 화면에 표시됩니다.
- 생성한 캠페인 상세 화면으로 이동할 수 있습니다.
- 새로고침 후에도 캠페인이 유지됩니다.

권한 조건:

- 캠페인 생성과 수정은 PM 조직의 `MANAGER` 이상 권한에서 확인합니다.

### 3.2 캠페인 상태 변경

캠페인 상태는 다음 값으로 표시됩니다.

- 초안
- 진행중
- 모집중
- 검토중
- 완료
- 종료

확인 항목:

- 캠페인 상태 변경 후 상세 화면의 상태 뱃지가 갱신됩니다.
- 사이드바 또는 캠페인 목록에도 변경된 상태가 반영됩니다.
- 권한이 없는 사용자는 상태 변경 버튼이 보이지 않거나 동작하지 않아야 합니다.

## 4. 캠페인 상세

### 4.1 화면 진입

캠페인 카드를 클릭하면 캠페인 상세 화면으로 이동합니다.

접속 경로:

```text
/campaigns/{campaignId}
```

상단에는 다음 6개 탭이 표시됩니다.

1. 캠페인 오버뷰
2. 팀 보드 보기
3. 자료 검수
4. 참여자 설정
5. 캠페인 성과/KPI
6. 매칭 탭

외부 파트너 계정은 `캠페인 성과/KPI` 탭이 보이지 않아야 합니다.

### 4.2 캠페인 오버뷰 탭

확인 항목:

- 캠페인 이름
- 상태 뱃지
- 캠페인 기간
- 전체 업무 수
- 완료 업무 수
- 검수 대기 수
- 지연 업무 수
- KPI 성과 요약
- ESG 점수 패널

테스트 절차:

1. 캠페인 상세 화면에 진입합니다.
2. 오버뷰 탭이 기본으로 표시되는지 확인합니다.
3. 통계 카드의 수치가 표시되는지 확인합니다.
4. KPI 성과 요약의 `상세보기`를 클릭합니다.
5. `캠페인 성과/KPI` 탭으로 이동하는지 확인합니다.

### 4.3 캠페인 편집

권한 조건:

- 내 조직이 PM이어야 합니다.
- `MANAGER` 이상 권한이어야 합니다.

절차:

1. 캠페인 상세 우상단 `캠페인 편집` 버튼을 클릭합니다.
2. 이름, 기간, 색상, 요약 등을 수정합니다.
3. 저장합니다.

기대 결과:

- 캠페인 상세의 이름, 기간, 색상이 갱신됩니다.
- 사이드바와 캘린더의 색상, 이름도 함께 갱신됩니다.
- 권한이 없는 계정에서는 편집 버튼이 보이지 않아야 합니다.

## 5. 팀 보드와 업무 관리

### 5.1 캠페인 상세 팀 보드

캠페인 상세 화면의 `팀 보드 보기` 탭에서 캠페인 단위 업무를 관리합니다.

보드 컬럼은 다음과 같습니다.

- 백로그
- 진행 중
- 검수 요청
- 본사 승인 대기
- 수정 중
- 완료

### 5.2 마일스톤 추가

1. `업무 파트 / 마일스톤 생성하기`를 클릭합니다.
2. 마일스톤 생성 모드를 선택합니다.
3. 이름, 시작일, 종료일을 입력합니다.
4. 저장합니다.

기대 결과:

- 새 마일스톤이 캠페인 보드에 표시됩니다.
- 캘린더에도 마일스톤 일정이 반영됩니다.

### 5.3 업무 파트 추가

1. `업무 파트 / 마일스톤 생성하기`를 클릭합니다.
2. 업무 파트 생성 모드를 선택합니다.
3. 이름과 설명을 입력합니다.
4. 저장합니다.

기대 결과:

- 새 업무 파트가 업무 생성 시 선택 가능한 항목으로 표시됩니다.
- 새로고침 후에도 업무 파트가 유지됩니다.

### 5.4 업무 추가

1. `업무 추가`를 클릭합니다.
2. 제목, 마일스톤, 파트, 마감일, 우선순위를 입력합니다.
3. 저장합니다.

기대 결과:

- 새 업무가 보드에 표시됩니다.
- 업무 상태 변경 시 오버뷰 통계가 갱신됩니다.
- 업무 일정이 캘린더에 반영됩니다.
- 새로고침 후에도 업무가 유지됩니다.

### 5.5 전체 팀 보드

좌측 메뉴에서 `팀 보드`로 이동합니다.

URL:

```text
/team-board
```

확인 항목:

- 전체 업무 컬럼
- 회사 또는 캠페인별 그룹
- 검색
- 우선순위 필터
- 업무 카드

기대 결과:

- 캠페인 상세에서 생성한 업무가 전체 팀 보드에도 표시됩니다.
- 검색과 필터가 정상 동작합니다.
- 업무 상태 변경이 캠페인 상세에도 반영됩니다.

## 6. 캘린더

### 6.1 화면 진입

좌측 메뉴에서 `캘린더`로 이동합니다.

URL:

```text
/calendar
```

### 6.2 확인 항목

- 큰 달력
- 오늘 날짜 강조
- 월 / 주 / 아젠다 뷰 전환
- 캠페인 일정
- 마일스톤 일정
- 업무 일정
- 필터 토글

### 6.3 테스트 절차

1. 캠페인 기간이 캘린더에 표시되는지 확인합니다.
2. 마일스톤 일정이 표시되는지 확인합니다.
3. 업무 마감일이 표시되는지 확인합니다.
4. 일정 카드를 클릭해 상세 정보가 열리는지 확인합니다.
5. 가능한 경우 일정을 드래그해 날짜를 변경합니다.
6. 새로고침 후 변경 내용이 유지되는지 확인합니다.

추가 확인:

- `+N개 더` 클릭 시 상세 목록이 표시됩니다.
- 필터 상태가 새로고침 후 유지됩니다.
- 캘린더 export/import 기능을 확인합니다.

## 7. 캠페인 성과/KPI

### 7.1 캠페인 KPI

캠페인 상세 화면의 `캠페인 성과/KPI` 탭에서 캠페인별 KPI를 관리합니다.

처음에는 빈 상태이며 `프레임워크 불러오기`, `지표 추가` 버튼이 표시됩니다.

### 7.2 KPI 추가

1. `지표 추가`를 클릭합니다.
2. 다음 정보를 입력합니다.
   - 이름
   - 카테고리
   - 단위
   - 목표
   - 목표 타입
3. 저장합니다.

기대 결과:

- KPI 행이 추가됩니다.
- 목표값과 단위가 표에 표시됩니다.
- 상단 요약 카드가 갱신됩니다.

### 7.3 실측값 입력

1. KPI 행의 `실적` 버튼을 클릭합니다.
2. 실측값을 입력합니다.
3. 저장합니다.

기대 결과:

- 실측값이 표에 표시됩니다.
- 달성률이 계산됩니다.
- 오버뷰의 KPI 성과 요약이 갱신됩니다.

### 7.4 프레임워크 불러오기

1. `프레임워크 불러오기` 버튼을 클릭합니다.
2. 프레임워크를 선택합니다.
3. 적용합니다.

기대 결과:

- 여러 KPI가 한 번에 추가됩니다.

### 7.5 상위 KPI import

1. `지표 추가` 모달에서 `상위 KPI에서 import`를 클릭합니다.
2. 활성 상태의 상위 KPI를 선택합니다.
3. 캠페인이 기여할 목표값을 입력합니다.
4. 저장합니다.

기대 결과:

- 캠페인 KPI가 조직 KPI와 cascade 관계로 연결됩니다.
- 오버뷰와 KPI 탭에 관련 수치가 반영됩니다.

## 8. 조직 KPI

### 8.1 화면 진입

좌측 메뉴에서 `분기 목표` 또는 KPI 관련 메뉴로 이동합니다.

URL:

```text
/organization-kpis
```

### 8.2 확인 항목

- 상태 탭
  - 활성
  - 초안
  - 보관
- 기간 선택
  - 지난 분기
  - 이번 분기
  - 다음 분기
  - 연간
  - 전체
- KPI 생성
- KPI 수정
- KPI 상태 변경
- 상위 KPI 연결

권한 조건:

- HQ 계정은 본사 KPI를 관리합니다.
- 계열사 계정은 계열사 KPI를 관리합니다.
- 외부 파트너 계정은 해당 화면 접근이 제한되어야 합니다.

기대 결과:

- 조직 유형에 맞는 KPI만 생성/수정할 수 있습니다.
- 활성 상태의 KPI는 캠페인 KPI에서 import 대상으로 표시됩니다.

## 9. 자료 검수와 승인

### 9.1 화면 진입

캠페인 상세 화면의 `자료 검수` 탭으로 이동합니다.

자료 검수 탭은 다음 하위 탭으로 구성됩니다.

- 검수
- 승인
- 자료실

### 9.2 AI 검수 요청

1. `자료 검수` 탭으로 이동합니다.
2. `검수` 하위 탭을 선택합니다.
3. AI 검수 요청 생성 화면을 엽니다.
4. 검수할 파일 또는 자료를 업로드합니다.
5. 검수 결과가 생성되는지 확인합니다.

기대 결과:

- 파일 업로드 후 AI 검수 job이 생성됩니다.
- 진행률 또는 처리 상태가 표시됩니다.
- 완료 후 검수 결과 요약이 표시됩니다.
- 상세 보기에서 검수 결과를 확인할 수 있습니다.

### 9.3 검수 결과 확인

검수 결과에서 다음 항목을 확인합니다.

- 판단 등급
- 이슈 목록
- 문제 영역
- 수정 제안
- 승인 요청 생성 가능 여부

### 9.4 승인 요청

1. AI 검수 완료 자료를 선택합니다.
2. 승인 요청 메모를 입력합니다.
3. 승인 요청을 생성합니다.

기대 결과:

- 승인 요청 목록에 새 요청이 표시됩니다.
- 관련 담당자에게 알림이 생성됩니다.

### 9.5 승인 처리

1. 승인 권한이 있는 계정으로 로그인합니다.
2. `승인` 하위 탭으로 이동합니다.
3. 승인 요청 목록을 확인합니다.
4. 승인 또는 반려를 처리합니다.

기대 결과:

- 승인 또는 반려 후 상태가 갱신됩니다.
- 승인 처리 중 중복 클릭이 방지됩니다.
- 반려 사유가 필요한 경우 입력값이 저장됩니다.

## 10. 참여자 설정

### 10.1 화면 진입

캠페인 상세 화면의 `참여자 설정` 탭으로 이동합니다.

### 10.2 확인 항목

멤버는 조직별로 묶여 표시되며, PM 조직이 맨 위에 표시됩니다.

세 가지 초대 버튼:

- `팀원 추가`: 같은 회사 사람을 검색한 뒤 체크박스로 다중 선택하여 추가합니다.
- `협력사 GM 초대`: 외부 회사 GM 1명에게 초대 알림을 발송합니다.
- `협력사 그룹 초대`: 협력사 회사와 그 안의 사람들을 한 번에 초대합니다.

권한 조건:

- 팀원 추가는 `MANAGER` 이상 권한이 필요합니다.
- 협력사 초대 기능은 `MANAGER` 이상이면서 PM 조직일 때 사용할 수 있습니다.

기대 결과:

- 멤버 추가 또는 추방 시 참여자 목록이 갱신됩니다.
- 초대 대상 사용자에게 알림이 생성됩니다.
- 자기 자신은 추방할 수 없습니다.

## 12. 매칭 평가

### 12.1 기능 목적

매칭 평가는 캠페인 목표와 파트너 혜택을 기준으로 협업 적합도를 평가하는 기능입니다.

캠페인 담당자는 제안된 혜택을 확인하고, 평가 요청을 통해 파트너 적합도와 개선 방향을 확인할 수 있습니다.

### 12.2 접속 경로

매칭 기능은 두 위치에서 확인할 수 있습니다.

```text
/matching
/campaigns/{campaignId} 의 매칭 탭
```

전체 매칭 화면은 다음 탭으로 구성됩니다.

- 홈
- 혜택 목록
- 파트너 평가

### 12.3 매칭 평가 절차

1. 총괄 매니저 계정 또는 매니저 계정으로 로그인합니다.
2. `/matching` 화면 또는 캠페인 상세의 `매칭 탭`으로 이동합니다.
3. `혜택 목록` 탭으로 이동합니다.
4. 평가할 혜택을 선택합니다.
5. `평가하기` 또는 평가 요청 버튼을 클릭합니다.
6. 평가 요청이 시작되면 파트너 평가 화면으로 이동합니다.
7. 평가 결과가 표시되는지 확인합니다.

기대 결과:

- 혜택 목록이 정상 조회됩니다.
- 평가 요청 후 로딩 또는 처리 상태가 표시됩니다.
- 평가 완료 후 점수, 평가 요약, 개선 방향이 표시됩니다.
- 평가 실패 시 실패 상태 또는 안내 문구가 표시됩니다.

### 15.2 화면 진입

```text
/frames
```

6. 알림 클릭 시 읽음 처리되는지 확인합니다.
7. `모두 읽음 처리` 버튼을 눌러 미확인 개수가 `0`이 되는지 확인합니다.

알림 필터:

- 전체
- 미확인
- 업무
- QA
- 캠페인
- 일정
- 시스템

5. 일반 업무 알림이 생성되지 않는지 확인합니다.
6. 마감 초과 같은 중요 알림은 정책에 따라 생성될 수 있습니다.

### 16.4 프로필 이미지 테스트

1. `/settings`에 접속합니다.
2. 프로필 탭을 선택합니다.
3. 프로필 이미지 변경 모달을 엽니다.
4. 이미지를 선택한 뒤 저장합니다.
5. 헤더 프로필 이미지가 변경되는지 확인합니다.
6. 로그아웃 후 재로그인해도 이미지가 유지되는지 확인합니다.

### 16.5 계정/보안 테스트

2. 계정/보안 탭을 선택합니다.
