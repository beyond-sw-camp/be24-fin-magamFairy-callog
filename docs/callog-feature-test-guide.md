# 캘로그 기능 테스트 안내서

Callog를 처음 보는 사람도 주요 기능을 순서대로 확인할 수 있도록 정리한 테스트 안내서입니다.

## 1. 캠페인 프레임 사용 안내서

### 1.1 기능 목적

캠페인 프레임 라이브러리는 캠페인 문서 작성 및 검수 기준을 표준화하기 위한 기능입니다.

PM사, 본사, 협력사, 대행사는 캠페인 문서를 작성할 때 동일한 프레임 기준을 참고할 수 있으며, 작성된 문서는 AI 판사 기능을 통해 필수 항목, 톤앤매너, 금지어, 제출 규격 등을 검수할 수 있습니다.

### 1.2 화면 구성

캠페인 프레임 화면은 크게 `프레임 라이브러리`와 `AI 판사` 영역으로 구성됩니다.

#### 프레임 라이브러리

프레임 라이브러리에서는 등록된 표준 프레임 목록을 확인할 수 있습니다.

각 프레임 카드에서는 다음 정보를 확인할 수 있습니다.

- 프레임 유형
- 프레임명
- 검수 목적
- 사용 횟수
- 통과율
- 점수

#### AI 판사

AI 판사는 선택한 프레임 기준으로 문서를 검수하는 영역입니다.

문서를 업로드하면 다음 항목을 기준으로 검토 상태를 확인할 수 있습니다.

- 필수 입력 항목
- 사내 톤앤매너
- 금지어 / 금지 표현
- 채널 / 제출 규격

### 1.3 프레임 조회 방법

1. 캠페인 프레임 라이브러리 화면으로 이동합니다.
2. 등록된 표준 프레임 목록을 확인합니다.
3. 필요한 경우 상단 필터를 사용해 캠페인 방식을 선택합니다.
4. 정렬 기준을 선택하여 프레임을 확인합니다.
   - 점수 높은순
   - 사용 많은순
   - 통과율 높은순
5. 확인하려는 프레임 카드를 선택합니다.

### 1.4 프레임 상세 기준 확인

프레임 카드를 선택하면 해당 프레임의 검수 기준을 확인할 수 있습니다.

확인 가능한 항목은 다음과 같습니다.

- 필수 입력 항목
- 금지 표현
- 권장 표현
- 톤앤매너 가이드
- 승인 프로세스
- 프레임 성과 정보
- 프레임 점수

이 기준을 참고하여 캠페인 문서를 작성하거나 수정할 수 있습니다.

### 1.5 AI 판사로 문서 검수하기

1. 검수 기준으로 사용할 프레임을 선택합니다.
2. 오른쪽 AI 판사 영역에서 문서 업로드 영역을 클릭합니다.
3. 검수할 문서 파일을 업로드합니다.
4. AI 판사가 선택된 프레임 기준으로 문서를 검토합니다.
5. 검토 결과를 확인합니다.

검토 결과는 다음과 같이 표시됩니다.

- 검토 대기
- 적합
- 보완 필요

### 1.6 검수 결과 확인 항목

AI 판사는 업로드된 문서를 기준으로 다음 항목을 확인합니다.

#### 필수 입력 항목

캠페인 문서에 반드시 포함되어야 하는 정보가 누락되지 않았는지 확인합니다.

#### 사내 톤앤매너

문서의 표현 방식이 브랜드 또는 사내 기준에 맞는지 확인합니다.

#### 금지어 / 금지 표현

과장 표현, 부적절한 문구, 사용이 제한된 표현이 포함되어 있는지 확인합니다.

#### 채널 / 제출 규격

문서가 캠페인 채널이나 제출 형식에 맞게 작성되었는지 확인합니다.

### 1.7 사용 예시

예를 들어 쿠폰 할인 캠페인을 준비하는 경우 `쿠폰·할인 표준 프레임`을 선택합니다.

이후 캠페인 문서를 업로드하면 AI 판사가 할인율, 사용 기간, 사용 조건, 제외 대상 표기 여부 등을 검토합니다.

검수 결과에서 보완이 필요한 항목이 표시되면 해당 내용을 수정한 뒤 다시 검토할 수 있습니다.

### 1.8 주의사항

- 프레임은 캠페인 문서 작성 및 검수 기준으로 사용됩니다.
- 현재 화면에서는 프레임을 새로 생성하지 않고, 등록된 표준 프레임을 조회하여 사용합니다.
- AI 판사 결과는 검토를 돕기 위한 참고 자료이며, 최종 승인 여부는 담당자가 확인해야 합니다.
- 문서 내용이 부족하거나 형식이 맞지 않으면 정확한 검수 결과가 나오지 않을 수 있습니다.

## 2. 매칭 평가 기능 사용법

1. 각 팀에 배부된 총괄 매니저 계정 또는 매니저 계정으로 로그인합니다.
2. 화면 좌측 중앙의 캠페인 목록을 열고 각 팀별 테스트 캠페인 페이지로 이동합니다.
3. 매칭 탭의 `혜택 목록` 탭으로 이동합니다.
4. 화면 우측의 `평가하기` 버튼을 눌러 평가 시작 모달을 엽니다.
5. 테스트 혜택을 선택하고 `선택한 혜택 평가 요청`을 클릭합니다.
6. 자동으로 평가 결과 페이지로 이동됩니다.
7. 현재 대기 상태 표시가 미완성되어 있으므로, 1~2분가량 후 새로고침하면 결과가 나타납니다.

## 3. 접속 및 계정 안내

### 3.1 접속 주소

서비스 주소는 다음과 같습니다.

```text
https://www.magamfairy.kro.kr
```

### 3.2 계정 구조

회원가입은 외부 협력사를 위한 기능입니다.

본사 계정은 `admin`, `manager` 등 상위 권한 계정이 생성하여 전달하는 방식으로 설계되어 있습니다.

안내받은 계정으로 로그인하면 메인 대시보드 화면으로 이동합니다.

### 3.3 인사관리

`admin`과 `manager`는 우측 상단 메뉴 탭에서 인사관리 창을 사용할 수 있습니다.

인사관리에서는 하위 사용자의 정보를 수정할 수 있습니다.

- `admin`: 시스템을 사용하는 모든 사용자 관리
- `manager`: 자기 팀에 속한 사용자 관리

`admin`이 생성한 `manager`는 `generalmanager`로서 일반 `manager`와 권한은 같으나, `user`와 `manager`의 권한을 변경할 수 있습니다.

### 3.4 비밀번호 재설정 및 계정 삭제

비밀번호 재설정을 통해 계정의 비밀번호를 난수로 재생성할 수 있습니다.

삭제 버튼을 통해 계정을 삭제할 수 있습니다.

계정 삭제는 실제 데이터를 물리 삭제하지 않고, `enable` 값을 `1`에서 `0`으로 변경하여 비활성화되도록 설계되어 있습니다.

## 4. 전체 기능 테스트 가이드

### 4.1 시작하기

- 주소: `https://www.magamfairy.kro.kr/`
- 아이디: `admin`
- 비밀번호: `admin`

`admin` 계정은 모든 기능을 사용할 수 있습니다.

표시 약속은 다음과 같습니다.

- `[정상]`: 정상 동작
- `[버그]`: 버그 의심
- `[권한 필요]`: 특정 권한 필요
- `[자동 반영]`: 새로고침 없이 자동 반영

### 4.2 로그인

1. 위 주소에 접속합니다.
2. 아이디 `admin`, 비밀번호 `admin`을 입력합니다.
3. `Sign in`을 클릭합니다.

기대 결과:

- 대시보드 화면이 표시됩니다.
- 좌측 사이드바가 표시됩니다.

### 4.3 캠페인 만들기

1. 좌측 사이드바 `내 캠페인` 영역의 `+` 버튼을 클릭합니다.
2. 다음 정보를 입력합니다.
   - 이름: `여름 호텔 패키지`
   - 시작일: 오늘
   - 종료일: 오늘 + 30일
   - 색상: 보라
3. 생성합니다.

기대 결과:

- 사이드바에 새 캠페인 카드가 즉시 등장합니다.
- 선택한 색상의 띠가 카드에 표시됩니다.

추가 확인:

- 카드에 마우스를 올리면 0.2초 뒤 우측에 미리보기 패널이 표시됩니다.
- 카드 우클릭 시 컨텍스트 메뉴가 표시됩니다.
- 컨텍스트 메뉴의 수정, 완료, 일시정지 기능은 PM 조직이면서 `MANAGER` 이상 권한일 때만 노출됩니다.
- 카드 드래그로 순서를 변경할 수 있으며, 새로고침 후에도 순서가 유지됩니다.

### 4.4 캠페인 상세 화면

캠페인 카드를 클릭하면 캠페인 상세 화면으로 이동합니다.

상단에는 다음 6개 탭이 표시됩니다.

1. 캠페인 오버뷰
2. 팀 보드 보기
3. 검수/승인
4. 참여자 설정
5. 캠페인 성과/KPI
6. 매칭 탭

#### 캠페인 오버뷰 탭

확인 항목:

- 헤더에 큰 이름, 상태 뱃지, 기간이 표시됩니다.
- 상태 뱃지 클릭 시 6가지 상태를 변경할 수 있습니다.
  - 초안
  - 진행중
  - 모집중
  - 검토중
  - 완료
  - 종료
- 상태 변경 시 상세 화면과 사이드바 카드가 자동 갱신됩니다.
- 통계 카드 4개가 표시됩니다.
  - 전체 업무
  - 완료
  - 검수 대기
  - 지연
- KPI 게이지 도넛 중앙에 퍼센트 숫자가 표시됩니다.

#### 팀 보드 보기 탭

팀 보드는 `마일스톤 -> 업무 파트 -> 업무` 구조로 구성됩니다.

마일스톤 추가:

1. `+ 마일스톤 추가`를 클릭합니다.
2. 이름을 `디자인 완료`로 입력합니다.
3. 시작일과 종료일을 입력합니다.
4. 저장합니다.

기대 결과:

- 칸반에 새 행이 등장합니다.
- 캘린더에도 자동 등록됩니다.

업무 파트 추가:

1. `+ 업무 파트 추가`를 클릭합니다.
2. 이름을 `메인 비주얼`로 입력합니다.
3. 마일스톤을 `디자인 완료`로 선택합니다.
4. 저장합니다.

기대 결과:

- 칸반에 새 행이 등장합니다.
- 행 옆에 `0건`이 표시됩니다.

업무 추가:

1. `+ 업무 추가`를 클릭합니다.
2. 제목을 `히어로 시안 3개`로 입력합니다.
3. 마일스톤, 파트, 마감일, 우선순위를 입력합니다.
4. 저장합니다.

기대 결과:

- 칸반 `백로그` 컬럼에 카드가 등장합니다.
- 캘린더 마감일 칸에 업무가 자동 등록됩니다.
- 사이드바 캠페인 진행률이 갱신됩니다.
- 오버뷰 탭 통계 카드 숫자가 증가합니다.

업무 카드 조작:

- 카드 클릭 시 우측 상세 패널이 열립니다.
- 다른 곳을 클릭하면 상세 패널이 닫힙니다.
- 카드 드래그로 컬럼을 이동하면 진행률이 자동 갱신됩니다.

#### 참여자 설정 탭

멤버는 조직별로 묶여 표시되며, PM 조직이 맨 위에 표시됩니다.

세 가지 초대 버튼:

- `+ 팀원 추가`: 같은 회사 사람을 검색한 뒤 체크박스로 다중 선택하여 추가합니다.
- `협력사 GM 초대`: 외부 회사 GM 1명에게 초대 알림을 발송합니다. 수락해야 멤버가 됩니다.
- `협력사 그룹 초대`: 협력사 회사와 그 안의 사람들을 한 번에 초대합니다.

권한 조건:

- 팀원 추가는 `MANAGER` 이상 권한이 필요합니다.
- 협력사 초대 기능은 `MANAGER` 이상이면서 PM 조직일 때 사용할 수 있습니다.

기대 결과:

- 멤버 추가 또는 추방 시 해당 사용자의 사이드바도 자동 갱신됩니다.
- 자기 자신은 추방할 수 없습니다.

#### 캠페인 성과/KPI 탭

처음에는 빈 상태이며 `프레임워크 불러오기`, `지표 추가` 버튼이 표시됩니다.

KPI 추가:

1. `지표 추가`를 클릭합니다.
2. 다음 정보를 입력합니다.
   - 이름: `이메일 오픈율`
   - 카테고리: `Engagement`
   - 단위: `%`
   - 목표: `25`
3. 저장합니다.

기대 결과:

- 표에 새 행이 등장합니다.
- `목표 25%`, `실측 -`, `달성률 -`가 표시됩니다.

실측값 입력:

1. 행의 연필 아이콘을 클릭합니다.
2. 실측값을 `28`로 입력합니다.
3. 저장합니다.

기대 결과:

- `실측 28%`, `달성률 112%`가 표시됩니다.
- 상단 요약 카드가 갱신됩니다.
  - 전체
  - 측정 완료
  - 평균
  - ESG

프레임워크 불러오기:

1. `프레임워크 불러오기` 버튼을 클릭합니다.
2. 프레임워크를 선택합니다.
3. 적용합니다.

기대 결과:

- 여러 KPI가 한 번에 추가됩니다.

분석 메모:

- 표 아래 메모 박스에 텍스트를 입력하고 저장합니다.
- 새로고침 후에도 메모가 유지되는지 확인합니다.

### 4.5 캠페인 편집

권한 조건:

- 내 조직이 PM이어야 합니다.
- `MANAGER` 이상 권한이어야 합니다.

절차:

1. 캠페인 상세 우상단 `편집` 버튼을 클릭합니다.
2. 이름, 기간, 색상, 요약 등을 수정합니다.
3. 저장합니다.

기대 결과:

- 사이드바와 캘린더의 색상, 이름이 즉시 갱신됩니다.

추가 확인:

- 사이드바 카드 우클릭 후 `수정`을 클릭하면 빠른 편집 모달이 열립니다.
- 컨텍스트 메뉴에서 `완료 처리`, `일시정지`, `재개` 상태 변경을 확인합니다.

### 4.6 캠페인 소개 페이지

진입 방법:

- 캠페인 상세 화면에서 `소개 페이지`로 이동합니다.
- 또는 URL을 `/campaigns/<id>/intro` 형식으로 변경합니다.

확인 항목:

- 빵부스러기: 캠페인 이름, 캠페인 소개
- 큰 헤더: 이름, 상태 뱃지, RFP 코드, `Verified by 한화`
- 마감 카운트다운: `D-15` 같은 큰 숫자
- 우상단 편집 버튼은 권한이 있을 때만 표시됩니다.

편집 모드:

1. 편집 버튼을 클릭합니다.
2. 입력 칸이 활성화되는지 확인합니다.
3. 저장 또는 취소를 클릭합니다.

### 4.7 내보내기

권한 조건:

- `MANAGER` 이상이어야 합니다.
- PM 조직이어야 합니다.

절차:

1. 캠페인 상세 우상단 `내보내기`를 클릭합니다.
2. 형식을 선택합니다.
   - `Executive Summary`: PDF, 1페이지, 권장
   - `Full Performance Report`: PDF, 다중 페이지
   - `Excel 데이터`: CSV
3. 섹션 5개 중 필요한 항목을 선택합니다.
   - 캠페인
   - 멤버
   - 업무
   - KPI
   - ESG
4. 다운로드합니다.

기대 결과:

- `생성 중...` 표시 후 파일이 자동 다운로드됩니다.

버그 의심 상황:

- 빈 PDF가 생성됩니다.
- 글씨가 깨집니다.
- 무한 로딩이 발생합니다.
- 모든 섹션을 해제했는데 CSV 다운로드가 가능합니다.

### 4.8 사이드바 KPI 보기 모드

사이드바 위쪽 보기 모드 토글을 클릭합니다.

모드:

- `Compact`: 캠페인 이름과 진행률만 표시
- `KPI`: 카드 확장, 핵심 KPI, D-Day, 멤버 아바타 표시

기대 결과:

- 새로고침 후에도 선택한 모드가 유지됩니다.
- 업무 완료 시 진행률이 자동 갱신됩니다.

### 4.9 캘린더

좌측 메뉴에서 `캘린더`로 이동합니다.

URL:

```text
/calendar
```

화면 구성:

- 큰 달력
- 오늘 강조
- 상단 월 / 주 / 아젠다 뷰 전환
- 우측 사이드바
  - 내 캠페인
  - 캠페인 토글
  - 마감 토글
  - 마일스톤 토글
  - 업무 토글
  - 내 일정만 토글

일정 추가:

1. 날짜 칸에 마우스를 올립니다.
2. 우상단 `+` 버튼을 클릭합니다.
3. 종류를 선택합니다.
   - 업무
   - 마일스톤
   - 캠페인
4. 정보를 입력합니다.
5. 저장합니다.

일정 이동:

1. 카드를 다른 날짜로 드래그합니다.
2. 확인 모달이 표시되는지 확인합니다.
3. `확인`을 클릭합니다.

기대 결과:

- 카드가 이동됩니다.
- 토스트 알림이 표시됩니다.
- 다른 사용자 화면에도 자동 갱신됩니다.

버그 의심 상황:

- 확인 모달 없이 바로 이동됩니다.
- 새로고침하면 원래 위치로 돌아갑니다.

추가 확인:

- 카드 클릭 시 우측 상세 패널이 열립니다.
- 다른 곳을 클릭하면 상세 패널이 닫힙니다.
- 카드 양 끝을 드래그해 기간을 늘리거나 줄일 수 있습니다.
- 기간 변경 시 확인 모달이 표시됩니다.
- `+N개 더` 클릭 시 작은 모달이 표시됩니다.
- 우측 사이드바 토글 상태가 새로고침 후에도 유지됩니다.
- 뷰 전환 시 URL에 `?view=week` 같은 쿼리가 추가됩니다.

### 4.11 자주 보는 정상 동작

정상 동작 예시는 다음과 같습니다.

- 캠페인 카드에 마우스를 올리면 0.2초 후 패널이 표시됩니다.
- 한 날짜 칸에 카드가 3개 초과로 있을 때 `+2개 더` 같은 표시가 나옵니다.
- 권한이 없을 때 편집 또는 내보내기 버튼이 보이지 않습니다.
- KPI 실측값이 비어 있으면 달성률이 `-`로 표시됩니다.
- 다른 사람이 추가한 캠페인이 1~2초 안에 사이드바에 표시됩니다.

버그 의심 상황은 다음과 같습니다.

- 흰 화면과 콘솔 빨간 에러가 표시됩니다.
- 모달이 닫히지 않습니다.
- 저장 후 새로고침해야만 변경 내용이 보입니다.
- 일정을 옮긴 뒤 새로고침하면 원래 위치로 돌아갑니다.

## 5. 알림 및 설정 테스트

### 5.1 알림 테스트

SSE 기반 알림 동작을 확인합니다.

1. 두 계정으로 각각 로그인합니다.
2. A 계정에서 B 계정에게 업무를 배정합니다.
3. B 계정의 헤더 알림 개수가 증가하는지 확인합니다.
4. B 계정에서 `/notifications`에 접속합니다.
5. 새 알림이 목록에 표시되는지 확인합니다.
6. 알림 클릭 시 읽음 처리되는지 확인합니다.
7. `모두 읽음 처리` 버튼을 눌러 `unreadCount`가 `0`이 되는지 확인합니다.

### 5.2 알림 설정 테스트

1. `/settings`에 접속합니다.
2. 알림 탭을 선택합니다.
3. 업무 알림을 OFF로 변경합니다.
4. 다른 계정에서 업무를 배정합니다.
5. 일반 업무 알림이 생성되지 않는지 확인합니다.
6. 마감 초과 같은 `CRITICAL` 알림은 설정과 관계없이 생성될 수 있습니다.

### 5.3 다크모드 테스트

1. `/settings`에 접속합니다.
2. 테마/UI 탭을 선택합니다.
3. 다크 모드를 클릭합니다.
4. 헤더, 사이드바, 설정 페이지, 알림 센터가 함께 다크 테마로 바뀌는지 확인합니다.
5. 새로고침 후에도 다크 모드가 유지되는지 확인합니다.

### 5.4 프로필 이미지 테스트

1. `/settings`에 접속합니다.
2. 프로필 탭을 선택합니다.
3. 프로필 이미지 변경 모달을 엽니다.
4. 이미지를 선택한 뒤 저장합니다.
5. 헤더 프로필 이미지가 변경되는지 확인합니다.
6. 로그아웃 후 재로그인해도 이미지가 유지되는지 확인합니다.
